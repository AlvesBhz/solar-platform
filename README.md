# solar-platform

Projetos digitais do Solar do Espinhaço.

| Pasta | O que é |
|---|---|
| `site/` | Site da pousada (estático, publicado no GitHub Pages), em português, inglês e espanhol |
| `site/database/` | Proposta do banco de reservas (Supabase/PostgreSQL): schema, testes, DER (`der.html`) e instruções no `README.md` |
| `guia-do-hospede/` | Guia digital do hóspede |
| `design-system/` | Componentes e padrões visuais |
| `solar-inspect/` | App de vistorias |

## Banco de reservas

- **Como funciona e como testar:** `site/database/README.md`
- **Diagrama (DER):** `site/database/der.html`. Ao clicar numa tabela, mostra cada campo com explicação, exemplo, ligações e regras.
- **Dicionário de dados para validação** (documento compartilhado com o proprietário): explica cada campo em linguagem simples e lista as decisões em aberto.
